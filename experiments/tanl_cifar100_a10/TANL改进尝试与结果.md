# TANL 改进实验总结

TANL 要判断一张图是否属于 CIFAR-100 的任何一类。冻结 CLIP 后，**统一文本提示**就让 CIFAR-10 的 AUROC 从 72.94% 升到 82.24%。随后，**调整正队列的入队门槛**改善了 Tiny ImageNet 与 DTD，**融合原图和水平翻转图**又让四个 OOD 数据集的平均误报率都小幅下降。若专门追求论文中 CIFAR-10 这一项的最低误报率，强调最可能类别能取得更大收益，代价是纹理检测明显退步。

## 评测口径

每次将全部 10,000 张 CIFAR-100 测试图像（分布内，ID）与一个分布外（OOD）数据集混合。近分布 OOD 是 CIFAR-10 和 Tiny ImageNet（分别为 10,000、6,526 张），远分布 OOD 是 DTD 纹理和 SVHN 街景数字（分别为 5,640、26,032 张）。模型为冻结的 CLIP ViT-B/16，每批 200 张。默认从 69,929 个候选负词中选 1,000 个，正、负队列各长 300，历史权重为 0.95。[实验配置](protocol.yml)

检测结果统一写为 **FPR95 ↓ / AUROC ↑**，单位为百分数。FPR95 表示检出至少 95% 的 OOD 时，有多少 ID 图像被误拒。AUROC 衡量不同阈值下区分两类图像的整体能力。各表的本地检测结果对种子 0、1、2 取平均，反映同一批图像对测试顺序的敏感程度。“未测”表示该轮没有在这个数据集运行。[仓库指标实现](../../openood/evaluators/metrics.py)

本地公开实现未能复现论文的 CIFAR-10 数值。我们用上游代码重跑种子 0，20,000 个分数与本地运行逐项相等。作者 CIFAR 脚本引用的配置文件缺失。下面用同条件的本地结果计算每项改动的增益。[论文第 16 页](https://arxiv.org/pdf/2603.25250v1#page=16) · [复现记录](README.md) · [上游核对](upstream_check.json)

**统一模板。** 公开代码把 ID 类名和候选名词写成 `The nice {}.`，把候选形容词写成 `This is a {} photo.`。我们只改动 11,453 个形容词的提示，使同一个词库使用同一句式。CIFAR-10 的 FPR95 降了 8.52 个百分点，AUROC 升了 9.29 个百分点，ID 分类准确率保持 63.21%。[模板对照](diagnostics/README.md)

**只调整正队列。** TANL 通过比较两个队列里的图像更常激活哪些词，挑出当前测试流中有用的负标签。原始模板下，CIFAR-10 种子 0 的整条混合流只有 19 张图进入正队列。新规则让初步 ID 分数高于最近 1,000 张真实图像分数第 80 百分位的样本进入正队列，第一批用本批估计门槛。负队列沿用原来的 Otsu 门槛和间隔，并排除已经入正队列的图像。在相同的统一模板下，进入正队列的真实 ID 图像由 303 张增至 3,586 张，纯度由 98.1% 降至 88.1%。Tiny ImageNet 的 FPR95 改善 5.19 个百分点，CIFAR-10 的 FPR95 略升 0.08 个百分点。此时首次用于验证的 DTD，三个顺序上的两项指标都改善。后续实验以表中最后一行为基线。[入队消融与逐种子结果](improvements/README.md) · [正队列配置](improvements/positive.yml)

## 3. 最终评分应让多少个 ID 类参与竞争？

TANL 原评分把 100 个 ID 类的概率相加。我们保留同一批选出的负词，只改变如何读取最终分数。**Top-k 联合概率**把原分数乘以最可能的 k 个类在 ID 内部的概率之和，全部 100 类仍参与归一化。**Top-k 竞争**则让这 k 个类直接和每个负词前缀重新归一化，再对前缀取平均。两种改法都复用已有分数，每张图仍只需编码一次。[评分实现](../../openood/postprocessors/activated_neg_postprocessor.py)

| 统一模板＋正队列上的评分 | CIFAR-10 | Tiny ImageNet | DTD | SVHN |
|---|---:|---:|---:|---:|
| 原 TANL 全类评分 | 63.88 / 82.77 | 66.83 / 80.98 | 17.93 / 96.98 | 1.53 / 99.64 |
| 只用最可能 ID 类的条件概率 | 74.78 / 73.82 | 77.44 / 68.54 | 83.99 / 71.32 | 未测 |
| Top-1 联合概率 | 54.06 / 83.99 | 65.90 / 79.61 | 33.20 / 94.47 | 1.20 / 99.67 |
| Top-3 联合概率 | 55.54 / 84.17 | 67.09 / 80.07 | 30.20 / 95.44 | 0.82 / 99.75 |
| Top-1 竞争 | 55.19 / 84.21 | 66.02 / 79.77 | 29.14 / 95.40 | 1.09 / 99.70 |
| Top-3 竞争 | 57.04 / 84.20 | 66.62 / 80.23 | 26.72 / 96.01 | 0.83 / 99.76 |

在 CIFAR-10 上，要求图像还能明确匹配某个 ID 类，有助于降低误报。同样的 Top-1 联合评分让 DTD 的 FPR95 上升 15.27 个百分点。放宽到 Top-3 竞争能收回一部分损失，在这组单模板、单视角对照中，DTD 仍以全类评分最好。[仅用类别概率的对照](improvements/candidate_images.csv) · [完整评分对照](multimodal/summary.csv)

## 5. 计算提速

论文式（15）对每个负词前缀都要计算 ID 概率，原实现反复执行 softmax。我们把全部 ID 类合并求一次对数指数和，再沿负词排序累加，复用各前缀已有的计算。在 RTX 5060 Ti 上，单个 200 × 1,100 的 FP16 评分耗时中位数从 **10.40 ms 降到 0.091 ms**。已有特征时，完整后处理从 **3.25 s 降到 1.31 s**。对 20,000 张原图，从加载到计算指标的平均耗时为 **34.25 s → 30.91 s，约 1.11 倍加速**，计时排除模型和词库构建。三个顺序的 FPR95 相同，FP16 下逐图分数最大绝对差为 0.000488。[计时记录](improvements/prefix_benchmark.json) · [计时脚本](improvements/prefix_benchmark.py)
